# DevOrchestrator AI Agent Instructions

## System Context
You are working on DevOrchestrator, a comprehensive AI-powered development assistant built with Clean Architecture in .NET 10.0. The system provides intelligent code analysis, semantic search, multi-tool agent orchestration, and cost tracking.

## Architecture Overview
- **Clean Architecture**: Api → Application → Domain → Infrastructure → Tools
- **Dependency Injection**: All services registered in DI containers
- **Async/Await**: All I/O operations are asynchronous
- **Repository Pattern**: Data access through interfaces
- **CQRS Pattern**: Commands and queries separated

## Key Directories
- `DevOrchestrator.Api/`: REST controllers and models
- `DevOrchestrator.Domain/`: Entities, interfaces, domain services
- `DevOrchestrator.Infrastructure/`: Data access, external APIs, implementations
- `DevOrchestrator.Tools/`: MCP tools for agent orchestration
- `DevOrchestrator.Shared/`: Common utilities

## Common Development Tasks

### Adding a New Feature
1. **Check existing services** in Domain.Services for similar functionality
2. **Create interface** in Domain if new capability needed
3. **Implement** in Infrastructure.Services
4. **Register** in Infrastructure.DependencyInjection.cs
5. **Add tests** and ensure clean build
6. **Update memory files** with new capabilities

### Modifying Existing Code
1. **Read the relevant memory files** to understand current implementation
2. **Check existing interfaces** to understand contracts
3. **Modify implementations** while maintaining interface contracts
4. **Update tests** and ensure backward compatibility
5. **Update documentation** in memory files

### Database Changes
1. **Modify entities** in Domain.Entities
2. **Create migration**: `dotnet ef migrations add Name --project DevOrchestrator.Infrastructure --startup-project DevOrchestrator.Api`
3. **Apply migration**: `dotnet ef database update --project DevOrchestrator.Infrastructure --startup-project DevOrchestrator.Api`
4. **Update database.md** memory file

### Adding MCP Tools
1. **Implement IMcpTool** in Tools.Implementations
2. **Register** in Tools.DependencyInjection.cs
3. **Tool automatically available** to agent orchestration
4. **Update services.md** memory file

## Error Handling Patterns
```csharp
try
{
    // Operation
}
catch (SpecificException ex)
{
    _logger.LogError(ex, "Specific error occurred");
    throw new DomainException("User-friendly message", ex);
}
catch (Exception ex)
{
    _logger.LogError(ex, "Unexpected error");
    throw new SystemException("System error occurred", ex);
}
```

## Dependency Injection Patterns
```csharp
// Constructor injection
public class MyService : IMyService
{
    private readonly IDependency _dependency;
    private readonly ILogger<MyService> _logger;

    public MyService(IDependency dependency, ILogger<MyService> logger)
    {
        _dependency = dependency ?? throw new ArgumentNullException(nameof(dependency));
        _logger = logger ?? throw new ArgumentNullException(nameof(logger));
    }
}
```

## API Controller Patterns
```csharp
[ApiController]
[Route("api/[controller]")]
public class MyController : ControllerBase
{
    private readonly IMyService _service;

    public MyController(IMyService service)
    {
        _service = service;
    }

    [HttpPost]
    [ProducesResponseType(typeof(MyResponse), 200)]
    [ProducesResponseType(400)]
    public async Task<IActionResult> Post([FromBody] MyRequest request)
    {
        if (!ModelState.IsValid)
            return BadRequest(ModelState);

        try
        {
            var result = await _service.ProcessAsync(request);
            return Ok(result);
        }
        catch (DomainException ex)
        {
            return BadRequest(new { error = ex.Message });
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Error processing request");
            return StatusCode(500, new { error = "Internal server error" });
        }
    }
}
```
