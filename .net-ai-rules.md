For **.NET 10 (2026)**, the industry has standardized on a `.cursorrules` or `ai-rules.md` file that focuses on **Native AOT**, **Signal-based reactivity**, and the **Microsoft.Extensions.AI** abstractions.

Below is a best-practice ruleset designed for a professional .NET environment. You can place this in your project root to guide AI coding assistants (like Cursor, GitHub Copilot, or Windsurf).

---

## .net-ai-rules.md

### 1. General Principles
* **Framework:** Target **.NET 10.0** and **Angular 21+** (Standalone APIs).
* **Paradigm:** Favor **Functional** and **Declarative** patterns over heavy inheritance.
* **Performance:** Prioritize **Native AOT** compatibility. Avoid `Reflection.Emit` and unbounded dynamic types.
* **Naming:** Use PascalCase for classes/methods, camelCase for local variables/private fields (prefixed with `_`).

---

### 2. C# & .NET 10 Standards
* **Immutability:** Use `public record` for DTOs and Events. Use `public sealed class` for Entities.
* **Primary Constructors:** Use Primary Constructors for Dependency Injection in classes and records.
* **Required Members:** Use the `required` keyword and `init` properties for object initializers instead of bloated constructors.
* **Collections:** Use `FrozenDictionary<TKey, TValue>` and `FrozenSet<T>` for read-only lookup data.
* **Logging:** Use `[LoggerMessage]` source generators for high-performance logging.

---

### 3. Architecture & Data
* **Clean Architecture:** Strictly separate **Domain**, **Application**, **Infrastructure**, and **Web/API** layers.
* **Result Pattern:** Do not use exceptions for business logic. Use `ErrorOr<T>` or `Ardalis.Result<T>`.
* **Validation:** Use **FluentValidation** with `IValidator<T>` injected into endpoints.
* **Mapping:** Prefer **Mapperly** (Source Generation) over AutoMapper to ensure AOT compatibility and performance.
* **Background Jobs:** Use **Hangfire** for persistent tasks; use `BackgroundService` only for simple, non-critical polling.

---

### 4. AI & LLM Integration
* **Abstractions:** Use `Microsoft.Extensions.AI` (e.g., `IChatClient`, `IEmbeddingGenerator`) instead of provider-specific SDKs.
* **Dependency Injection:** Register AI clients in `Program.cs` using the `.AsBuilder()` pattern to allow for middleware (caching, telemetry).
* **Function Calling:** Use the `[Description]` attribute on methods intended for LLM tool-calling to provide clear metadata.

---

### 5. Web API & Middleware
* **Minimal APIs:** Use Minimal APIs for all new endpoints. Use **Endpoint Filters** for cross-cutting concerns (Auth, Validation).
* **Caching:** Use `HybridCache` for all caching needs to prevent cache stampedes and support L1/L2 layers.
* **Real-time:** Use **SignalR** with the MessagePack protocol for binary efficiency.

---

### 6. Code Style & Formatting
```csharp
// Example of the expected style:
public sealed class CreateBookingRequest 
{
    public required Guid WorkspaceId { get; init; }
    public required DateTimeOffset StartTime { get; init; }
}

public partial class BookingService(ILogger<BookingService> logger, IRepository repo) 
{
    [LoggerMessage(Level = LogLevel.Information, Message = "Creating booking for {WorkspaceId}")]
    public partial void LogCreation(Guid workspaceId);
}
```

---

### 7. Explicit Forbidden Patterns
* **No `ArrayList` or `Hashtable`**: Use generic collections only.
* **No `Task.Wait()` or `.Result`**: Use `await` exclusively to prevent deadlocks.
* **No Manual JSON Parsing**: Use `System.Text.Json` source generators for `STJ` serialization.
* **No Logic in Controllers**: Keep Minimal API lambdas thin; delegate to Application Services.
